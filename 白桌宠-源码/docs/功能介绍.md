# 桌宠「白」— 功能与用法总手册

纯 C（Win32 + GDI+）写的桌面宠物，无第三方库。分层窗口逐像素透明，不占任务栏、不进 Alt-Tab。
本体目录：**`D:\桌宠\c版\`**，所有路径相对 exe 推导 —— **整个文件夹拷到任何位置都能跑**。

> 本文按代码实测写，不是设计稿。核对时间 2026-10-21。

---

## 一、启动与退出

| 方式 | 做法 |
|---|---|
| 单只 | 双击桌面「白」快捷方式，或 `D:\桌宠\c版\pet.exe` |
| 三只同屏 | `python launch_three.py`（先 taskkill 再起三只，打印 `alive 3/3`） |
| 退出 | 右键菜单「退出」→ 说 `Bye!` 后下沉离场，窗口销毁干净 |

启动动画：从屏幕下方升起探头，说一句 `Hi!`。

### 命令行参数（多实例）

```
pet.exe --slot N --name 白2 --model qwen3.8-flash --backend local --skin 白2
              --base https://... --keyfile D:\keys\deepseek.txt
```

| 参数 | 作用 | 备注 |
|---|---|---|
| `--slot N` | 出生位，从屏幕右往左排 | N = 0~5，越界归 0 |
| `--name X` | 头顶名牌 + 默认皮肤名 | 中文名必须走 python/宽字符启动，**别用 cmd** |
| `--model M` | 这只白的专属模型 | 写进 `PET_LLM_MODEL` 环境变量，子进程继承 |
| `--backend` | `qwen` / `local` / `ma` | 默认 local |
| `--skin X` | 指定皮肤目录 `assets\X\` | 不给则跟 `--name` 同名 |
| `--base URL` | 换 OpenAI 兼容服务商 | 写进 `PET_LLM_BASE`，**本地管道和多智能体两个后端都认**（DeepSeek/智谱/本机 Ollama、llama.cpp） |
| `--keyfile 路径` | 换密钥文件 | 写进 `PET_LLM_KEYFILE`，**第一行=密钥原文，路径不能带空格** |

`launch_three.py` 当前配置：白=`qwen3.8-max`、白2=`qwen3.8-flash`、白3=`qwen3.6-plus`，全走本地管道。加第四只改 `INST` 数组（`--slot 3`）。

## 二、鼠标操作

| 动作 | 反应 |
|---|---|
| 左键点**头**（立绘上 38%） | 眨眼 + 随机台词 + 弹输入框 |
| 左键点**身体**（下 62%） | 鞠躬 900ms → **坐下保持跪坐**；跪坐中再点一下才起身 |
| 按住**拖动** | 换「被拎起」姿势，跟手 1:1 不抖（屏幕坐标算偏移） |
| **双击** | 简易模式开关：静默，无气泡、无弹框，连 Hi/Bye 也省 |
| **右键** | 弹菜单 |

### 散步中的鼠标悬停（三区，200ms 轮询）

| 停在 | 反应 |
|---|---|
| 头 | 害羞停步 +「……别、别摸头。害羞。」 |
| 身体 | 眨眼 |
| 脚 | 绊倒压扁 450ms +「哇——！绊、绊倒了。笨蛋脚。」 |

**跪坐中一律不打扰**（不响应悬停、不眨眼切图）。

## 三、键盘

| 键 | 作用 |
|---|---|
| `Ctrl + E` | 切换 Q 版形象（放 `assets\桌宠Q版.png` 自动换真图，否则色块 chibi 占位） |
| `←` `→` | 散步时改行走方向（向左走自动镜像立绘） |
| 任意可打印字符 | 输入框打字 |
| `Backspace` | 删字 |
| `Enter` | 提交 |
| `Esc` | 关闭输入框 |
| `Ctrl + C` / `Ctrl + V` | 输入框内复制/粘贴 |

> 中文输入法下**第一次 Enter 只提交候选词**，第二次才真正发送 —— 这是 IME 标准行为，不是 bug。

## 四、聊天

- 水彩输入条素材自带「跟白说：」标签，文字与光标从标签后起步。
- 输入框可见宽度 **12 个汉字**（`VIS_CHARS`）；超长时**前 4 字固定 + 省略号 + 尾部到光标**，中间滚。
- 回车发送 → 回复**逐 token 流式**打进气泡，能看到气泡一点点长大。
- 气泡是卷轴材质**九宫格拉伸**：左端蝴蝶结、右端折角爱心永不变形，只拉中间素纸；下方羽毛笔独立装饰。
- 气泡宽高由 `bubble.h` 尺寸引擎按**字数**实时算：字号 18px（原规格 14 → v12 的 16 → 2026-10-21 再大一档）、行距 1.5 倍、超宽封顶自动折行（按代码点计数，中文 3 字节不会算成 3 个字）。
- 全链路 UTF-8，实测零乱码。

### 推理后端（右键菜单「推理后端」）

| 后端 | 说明 |
|---|---|
| **qwen CLI** | 无头 `qwen-code` 子进程（plan + safe-mode + 0 工具调用），回复整段进气泡 |
| **本地管道**（默认） | `inference_backend.exe` 直连 OpenAI 兼容端点，WinHTTP + SSE 流式，内置人设：简洁中文口语、不超三句、可傲娇 |
| **多智能体** | `ma.exe` 干活：拆任务 → 派工 → 三级验收 → 汇总 |

三条路都是**独立子进程 + 匿名管道**，与任何终端会话无关，互不串话。

**多智能体角色**子菜单：
- **主管（拆解+验收）** — 串行完整流程
- **员工A（单卡直通）** — 跳过拆解，更快
- 员工B / 员工C（并行）— **阶段2 才开**，菜单灰显 + `agent_config.h` 调度闸双保险

硬约束（`agent_config.h`）：单卡最多 5 任务、一轮最多 8 次模型调用、超时 5 分钟；上下文水位 75% 黄（裁历史）/85% 橙（强制压缩）/92% 红（拒开新任务）。产物落 `blackboard\artifacts\`。

**密钥**：优先级 `PET_LLM_KEY` > `PET_LLM_KEYFILE`（文件第一行=密钥原文）> `%USERPROFILE%\.qwen\settings.json` 的 `env.DASHSCOPE_API_KEY` > 同名环境变量。**不落任何代码和日志**。没 key 或断网自动回落 mock 一句，链路永不断。
> 注意：本机环境变量里有一把**过期**的同名 key，所以 settings.json 排在环境变量前面。
> 换非 dashscope 服务商时 settings.json 里没有它的字段名——只能走 `PET_LLM_KEY` 或 `--keyfile`。
> `enable_thinking:false` 是 dashscope 专属参数，两个后端都按 host 判定后才附加，避免严格端点回 400。

### 共享记忆

- 文件：**`memory\about_bro.txt`**（UTF-8，一行一条）。每次请求注入 system prompt。
- 对**任何一只**白说「**记住：xxx**」（全/半角冒号都行）→ 当场落盘、回「……记住了。」、**不走模型**。
- 三只桌宠白 + 终端白（Qwen Code）**读写同一份**，任何一只都认得哥哥。
- 近谈各自独立：本地管道每轮带最近 **8 轮**对话，谁被聊谁记得。
- 手工编辑该文件也行，下一条消息即生效（本地管道每次新起子进程）。控制行数省 token。

## 五、散步模式

- 菜单开关（带勾选）。沿工作区底边步进，`IDT_WALK` 50ms 一 tick。
- **帧数自适应**：启动时从 `assets\walk\walk01.png` 往下加载，遇到缺文件即停 → `walk_n` 就是实际帧数。**当前 9 帧**。
- **步速与帧数无关**：帧间隔 = `WALK_CYCLE_MS(1430) / walk_n`。9 帧 → 158ms，13 帧 → 110ms，**整周期恒为 1.43 秒**。换素材不会突然走快或走慢。
- 撞左右屏幕边缘 → **转身动画**：背面 380ms → 正面 380ms → 反向走回来，配台词「……痛。墙，笨蛋。」。缺正/背面素材时回落旧压扁动画。
- 散步中任何操作（点击、方向键、输入框打字）→ **原地停留 10 秒**（`walk_pause=200` tick），再次操作重置计时；没人理她自己接着走。

## 七、闹钟

1. 右键「闹钟」→ 输入框变时间模式（占位「……时间，HH:MM。」）
2. 输 `7:30` 回车 → 右下角挂铃铛图标，菜单项打勾
3. 到点：两种系统提示音交替 **500ms × 8 次** + 捂耳压扁动画 + 台词
4. 再点一次「闹钟」= 取消

铃铛素材缺失时是黄色圆角占位；音乐片段待哥哥给素材。

## 八、随机动作与节日

## 九、外观与显示

- **大小**：右键「大小」20% ~ 100%（20/40/60/80/100 五档）。DPI 感知，150% 缩放下渲染不虚。
- **防重影**：每帧清空画布 + 像素拷贝全覆盖，锁失败跳帧不送旧帧，水彩半透明纹理永不叠影。
- **眨眼**：每 2~4.5 秒随机一次，闭眼 220ms。站立用 `blink.png`，**跪坐用 `kneel_blink.png`**（同机位闭眼帧，切换零跳位）。散步中、鞠躬中、拖动中不眨。

## 十、皮肤系统（每只白独立形象）

**规则：`assets\<名字>\` 里放同名文件即覆盖公共形象，没放的自动回落 `assets\`。** 皮肤目录不存在 = 与单只完全一致。空皮肤目录实测 3/3 无回归。坏了删掉该文件即回落。

可覆盖清单（文件名一字不差）：

```

桌宠被鼠标拖动时形象.png                拖动姿态
桌宠跪坐形象1.png                       鞠躬后跪坐（必需）
front.png  back.png  blink.png          正面/背面/正面闭眼
kneel_blink.png                         跪坐闭眼帧
walk\walk01.png ~ walkNN.png            散步帧序列
输入条.png  聊天气泡.png                UI（换前先问白，九宫格切片参数是全局的）
```

`assets\白2\`、`assets\白3\` 已建，夹内有 `说明.txt` 清单。
**画布规格**：正/背/闭眼/跪坐两帧/walk 全部 **433×617、底边中心锚定**，不同画布切换必跳位。

## 十一、素材清单与加载规则

**必需**（缺失会弹错误框，回落路径显示在提示里）：
`桌宠站立形象1.png` `桌宠站立形象2.png` `桌宠跪坐形象1.png` `桌宠被鼠标拖动时形象.png` `聊天气泡.png`

**可选**（缺失自动降级，不报错）：
`front.png`（存在则兼任新待机站姿）`back.png` `blink.png` `kneel_blink.png` `输入条.png` `桌宠Q版.png` `walk\walk01~NN.png`

> `聊天框.png` 目前在库里但**代码未加载**（备用）。

### 换素材的正确姿势

1. 原图扔给白，白跑流水线：**降采样 → 边缘洪水抠白底（`min≥235 && max-min≤16`）→ 连通域去水印碎点（留 ≥最大域/50）→ 边界带羽化 → 并集包围盒 → 统一缩放、底边中心锚定补进画布**。
2. **同一动作的多帧必须一起重抠**（同一套参数、同一并集框），否则帧间风格断层。
3. 白发角色的羽化**只能作用于贴着透明带的边缘环**，全局白色距离 keying 会把头发裙摆亮部一起打半透明。
4. 验收压成**中灰底拼图**看——白底会藏掉白边光晕。
5. **改素材前先 `taskkill /IM pet.exe /F`**：GDI+ 会锁住 assets 下所有 PNG。
6. 原图归档进 `素材原图\`，**不删旧版**。

## 十三、编译

```
cd /d "D:\桌宠\c版"
set "PATH=D:\c语言\mingw64\bin;%PATH%"

windres -i pet.rc -O coff -o pet_res.res
gcc -O2 -mwindows -o pet.exe pet.c pet_res.res -lgdiplus -liphlpapi -lwinmm
gcc -O2 -o inference_backend.exe inference_backend.c -lwinhttp
gcc -O2 -o ma.exe ma.c -lwinhttp
```

> **必须带 `pet_res.res`**，否则图标和版本信息会丢。

## 十六、踩过的坑（改代码前先看）

| 现象 | 真因 / 解法 |
|---|---|
| 双击完全无反应 | 窗口类必须加 `CS_DBLCLKS`，否则 `WM_LBUTTONDBLCLK` 根本不投递 |
| 改素材/重编译/打 zip 报「正由另一进程使用」 | GDI+ 锁 assets，先 `taskkill /IM pet.exe /F` |
| 拖动时抖动+甩飞 | 必须用**屏幕坐标**算抓取偏移，客户区坐标会自激振荡 |
| 走路中窗口突然瞬移回右边缘 | `relayout` 锚点要用窗口水平中心，不能钉回右边缘 |
| 新旧美术混用期间一闪一闪 | 任何「回落旧图」的路径在散步中都是闪烁源，需按状态屏蔽 |
| 自动化截图截不到桌宠 | `CopyFromScreen` 捕不到分层窗口，改用 `PrintWindow` |
| 找不到桌宠窗口 | `FindWindowW` 对本机分层窗口返回 0，用 `EnumWindows` 按类名 `ShiroPetV2` 找 |
| 刚编译的 exe 启动被拦（`WinError 4551`） | Smart App Control 按**文件哈希**拦无签名新 exe，改名无效；**再 gcc 一次换哈希**即放行，别动系统配置 |
| 24bpp PNG 抠图改了没效果 | LockBits 改 alpha 会被静默丢弃，必须先转 32bppArgb 副本 |
| 画圆/椭圆什么都不显示 | 本机 GDI+ 椭圆系静默不显影，画圆要用分段弧拼 |
| 气泡九宫格一调就崩 | 本机 `GdipDrawImageRectRect(I)` 必崩（0xC0000005），改成加载时克隆九块 |
| 子进程闪出控制台窗 | `CREATE_NO_WINDOW \| CREATE_UNICODE_ENVIRONMENT` + `SetHandleInformation` 去掉句柄继承 |
| PowerShell 里 `Bitmap.Clone` 报 Out of memory | 传了 float 坐标，`Rectangle` 必须 `[int]` 强转 |
