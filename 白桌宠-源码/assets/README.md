# 素材说明

本仓库**不包含**美术资源，`assets/` 需要自行准备。运行所需文件名如下（必须一字不差）。

## 必需（缺失会弹错误框）

| 文件 | 用途 |
|---|---|
| `桌宠站立形象1.png` | 待机帧 1 |
| `桌宠站立形象2.png` | 待机帧 2 |
| `桌宠跪坐形象1.png` | 鞠躬后跪坐 |
| `桌宠被鼠标拖动时形象.png` | 拖动姿态 |
| `聊天气泡.png` | 回复气泡（九宫格切片参数写死在 `pet.c`） |

## 可选（缺失自动降级）

| 文件 | 用途 |
|---|---|
| `front.png` / `back.png` | 正面 / 背面（散步转身用） |
| `blink.png` / `kneel_blink.png` | 站立 / 跪坐闭眼帧 |
| `桌宠跪坐形象2.png` | 跪坐第二帧 |
| `输入条.png` | 聊天输入条（透明背景 + 保留输入区白纸） |
| `桌宠Q版.png` | `Ctrl+E` 切换的 Q 版形象 |
| `walk\walk01.png ~ walkNN.png` | 散步帧序列，缺帧即停 |
| `聊天框.png` | 当前代码未加载，可不提供 |

## 画布与锚点

- 站立/背面/闭眼/跪坐/拖动：**433 × 617**，底边中心锚定
- 散步帧：同画布、同锚定
- 换不同画布会跳位；同一动作多帧必须一起抠、同一并集框

## 皮肤

`assets\<名字>\` 放同名文件即覆盖公共素材，没放的回落到 `assets\` 根目录：

```
assets\
├─ 白2\说明.txt
├─ 白3\说明.txt
└─ walk\
```

空皮肤目录 = 完全使用公共形象。

## 抠图建议

1. 原图降采样 → 边缘洪水去白底（`min≥235 && max-min≤16`）
2. 连通域去水印碎点（保留面积 ≥ 最大域/50）
3. 边界带羽化（只作用于贴透明带的边缘环，别全局白距离 keying）
4. 并集包围盒 → 统一缩放 → 底边中心锚定补进 433×617 画布
5. 验收用中灰底拼图看，白底会藏掉白边光晕
