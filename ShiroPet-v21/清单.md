## 1. 运行环境

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 1703+ / Windows 11 | 依赖 `GetDpiForWindow` 等运行时探测；Win11 26200 实测 |
| CPU / 显卡 | 无特殊要求 | GDI+ 软件渲染，不需要独显 |
| 显示缩放 | 100% ~ 200% | 150% 实测；DPI 感知，不糊 |
| 运行库 | 无第三方 | 只用系统 `gdiplus` / `winhttp` / `iphlpapi` / `winmm` |
| 权限 | 普通用户 | 不写注册表、不装服务、不要管理员 |
| 安装路径 | 任意，可含中文 | 所有路径相对 exe 推导，整个目录可搬家 |
| 字体 | 微软雅黑 | 缺失时 GDI+ 回退，排版可能变 |
| 网络 | 仅推理时需要 | 断网或没 key 自动回落 mock，链路不断 |
| 推理端点 | 任意 OpenAI 兼容 | DashScope / DeepSeek / 智谱 / 本机 Ollama / llama.cpp |
| 密钥 | 可无 | 优先级：`PET_LLM_KEY` > `PET_LLM_KEYFILE` > `settings.json` > 环境变量 |
| 本机模型 | 可选 | Ollama `127.0.0.1:11434`；后端要求 key 非空，填占位符 |
| Python | 可选 3.8+ | 仅 `launch_three.py` 需要 |
| 多开 | `--slot 0~5` | 同屏建议 ≤3 只；同名同 slot 会重叠 |
| 杀软 / SAC | 需留意 | Smart App Control 会拦新编译的无签名 exe |
| 系统代码页 | 936 / 65001 正常 | ACP=1252 时 `GetModuleFileNameA` 中文路径变 `?`，见 P17 |
| 声音 | 系统提示音 | 闹钟用 `MessageBeep`，不需要音频文件 |

## 3. 踩坑清单

### 窗口 / 交互

| 编号 | 现象 | 真因 | 解法 |
|---|---|---|---|
| P01 | 双击完全没反应 | 窗口类没加 `CS_DBLCLKS` | 注册窗口类时加，否则 `WM_LBUTTONDBLCLK` 不投递 |
| P02 | 拖动抖动 + 甩飞 | 用客户区坐标算偏移会自激 | 改用**屏幕坐标**算抓取偏移 |
| P03 | 散步中窗口瞬移回右边缘 | `relayout` 锚点钉死在右边缘 | 锚点用窗口水平中心 |
| P04 | 新旧美术混用一闪一闪 | 任意「回落旧图」路径都是闪烁源 | 按状态屏蔽回落 |
| P05 | 跪坐后切图跳位 | 闭眼帧尺寸/锚点不一致 | 同机位 433×617、底边中心锚定 |

### 素材 / GDI+

| 编号 | 现象 | 真因 | 解法 |
|---|---|---|---|
| P06 | 改素材/重编译/打 zip 报「正由另一进程使用」 | GDI+ 锁住 assets 下 PNG | 先 `taskkill /IM pet.exe /F` |
| P07 | 24bpp PNG 抠图改了没效果 | `LockBits` 改 alpha 被静默丢弃 | 先转 32bppArgb 副本 |
| P08 | 画圆/椭圆什么都不显示 | 本机 GDI+ 椭圆系静默不显影 | 用分段弧拼圆 |
| P09 | 气泡九宫格一调就崩 | `GdipDrawImageRectRect(I)` 本机必崩（0xC0000005） | 加载时克隆九块再画 |
| P10 | 新抠的输入条显示成白方块 | 素材 100% 不透明，丢失 alpha | 洪水去白底 + 保留输入纸 + 羽化（见 P16） |
| P11 | 自动化截图截不到桌宠 | `CopyFromScreen` 捕不到分层窗口 | 改用 `PrintWindow` |
| P12 | `FindWindowW` 找不到桌宠 | 本机分层窗口返回 0 | `EnumWindows` 按类名 `ShiroPetV2` 找 |

### 进程 / 管道 / 网络

| 编号 | 现象 | 真因 | 解法 |
|---|---|---|---|
| P13 | 子进程闪出控制台窗 | 句柄继承 + 未加 `CREATE_NO_WINDOW` | `CREATE_NO_WINDOW \| CREATE_UNICODE_ENVIRONMENT` + `SetHandleInformation` |
| P14 | 子进程读完 stdin 不退出（双挂死） | 父端写句柄被子进程继承，永远等不到 EOF | 父端 `SetHandleInformation(in_w, HANDLE_FLAG_INHERIT, 0)` |
| P15 | `ma.exe` 报 `llm no content` | 它按非流式 JSON 解析，Ollama 默认回 SSE | 桥默认 `stream:false`；或请求体显式 `"stream":false` |
| P16 | 输入条白底、透明边缘丢失 | 素材 alpha 被压平 | 边缘洪水 + 输入区屏障 + 清孤立亮斑 + 0.6px 羽化 |
| P17 | 记忆读不到：`no memory file at D:\??\c?` | ACP≠936，`GetModuleFileNameA` 中文路径变 `?` | 用宽字符路径；或经本地桥用 Unicode 路径注入 |
| P18 | 云端 401 `invalid_api_key` | settings.json 里 key 过期 | 换 key，或改走本机 Ollama |
| P19 | qwen CLI 后端报找不到命令 | `qwen.cmd` 路径写死 | 运行时探测；没有就自动回落本地管道 |

<a id="编译相关的坑"></a>
### 编译 / 部署

| 编号 | 现象 | 真因 | 解法 |
|---|---|---|---|
| P20 | gcc 报 `CreateProcess: No such file or directory` | MinGW 在中文路径下把 `D:\c语言` 变成 `D:\c??`，找不到 `cc1.exe` | 在 ASCII 路径建目录联接再编译 |
| P21 | 刚编译的 exe 启动被拦（WinError 4551 / 应用控制策略） | Smart App Control 按文件哈希拦无签名新 exe | 覆盖已信任的旧路径，或重编译换哈希；不要动系统策略 |
| P22 | 图标/版本信息丢失 | 链接时没带 `pet_res.res` | `windres` 生成后一起链接 |
| P23 | PowerShell 里 `Bitmap.Clone` 报 Out of memory | 传了 float 坐标 | `Rectangle` 必须 `[int]` 强转 |

## 4. 打包清单

### 运行必需

| 文件 | 说明 |
|---|---|
| `pet.exe` | 桌宠本体 |
| `inference_backend.exe` | 本地管道推理子进程 |
| `ma.exe` | 多智能体引擎 |
| `assets\` | 公共形象、walk 帧、皮肤目录、气泡/输入条 |
| `memory\`（可空） | 共享记忆，首次「记住」会自动创建 |
| `启动白.cmd` | 便携启动入口 |

### 可选

- `launch_three.py` + `启动三只.cmd`（需 Python）
- `清单.md` / `LICENSE` / `使用说明.txt`

### 不要打包

| 内容 | 原因 |
|---|---|
| `memory\about_bro.txt` | 个人记忆 |
| `pet_debug.log` / `pet_child_err.log` / `blackboard\board.log` | 个人运行日志 |
| `blackboard\tasks\` / `artifacts\` | 个人任务产物 |
| `素材原图\` | 71 MB 原图归档 |
| `ma.exe.bak-*` / `pet_demo.exe` / `bubble_test.exe` | 备份与测试程序 |
| `聊天框.png` | 未加载 + 带生成水印，不随包分发 |
| 任何 key / settings.json | 密钥 |
