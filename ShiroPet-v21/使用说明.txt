桌宠「白」 v21 · 便携版使用说明
================================

一、启动
  双击「启动白.cmd」，或直接运行 pet.exe。
  启动后白会从屏幕下方升起，说一句 Hi!。
  右键点白 → 菜单：推理后端 / 工具 / 散步 / 闹钟 / 大小 / 皮肤 / 退出。

二、不配模型也能玩
  默认走本地管道；没有 key 时会回落 mock，固定说一句「管道是通的」。
  想接真模型，右键「推理后端」选一个，或按下面的方式启动：

    pet.exe --backend local --base https://api.deepseek.com/v1 --keyfile D:\keys\deepseek.txt

  本机 Ollama：
    set PET_LLM_KEY=local
    pet.exe --backend local --base http://127.0.0.1:11434/v1 --model qwen2.5:7b-instruct

三、多智能体
  右键「推理后端 → 多智能体」，可选主管 / 员工A。
  默认主管和员工A 共用一个端点；要分开：

    set PET_LLM_BASE=http://127.0.0.1:11434/v1
    set PET_LLM_MODEL=qwen2.5:7b-instruct
    set PET_LLM_KEY=local
    set MA_MANAGER_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
    set MA_MANAGER_MODEL=qwen3.8-max
    set MA_MANAGER_KEY=sk-...

  产物在 blackboard\artifacts\，任务卡在 blackboard\tasks\。

四、记忆
  memory\about_bro.txt，UTF-8，一行一条。
  把 about_bro.example.txt 复制成 about_bro.txt 再改；也可以直接对白说「记住：xxx」。
  三只白共享同一份记忆。

五、多开
  「启动三只.cmd」需要 Python 3；或手动：
    pet.exe --slot 1 --name 白2 --model qwen2.5:7b-instruct --backend local
  slot 0~5，同屏建议不超过 3 只。

六、出问题看哪里
  pet_debug.log       主程序日志（每行带 [pid]）
  pet_child_err.log   推理子进程的 stderr
  blackboard\board.log 多智能体调度记录
  完整环境要求与踩坑见 清单.md。

七、卸载
  直接删掉整个文件夹即可；不写注册表、不装服务。
